CustomTkinter Desktop App Template

Базовый шаблон настольного приложения на Python и CustomTkinter с переключением экранов, формами входа и регистрации и витриной UI-компонентов.

Назначение и возможности

Проект предназначен как стартовая точка для небольших графических приложений. Он показывает, как разделить главное окно, экраны и общие UI-фабрики без усложнения архитектуры.

Важно: это демонстрационный шаблон. Пользователи не сохраняются, API и база данных не подключены, а проверка входа использует пару admin / admin123.

Окно

Главное окно создаётся классом App, имеет стартовый размер 600×400 и поддерживает переключение страниц.

Авторизация

Есть отдельные формы входа и регистрации с проверкой обязательных полей и обработкой клавиши Enter.

UI-витрина

Демонстрационный экран показывает основные виджеты CustomTkinter, индикаторы, вкладки и переключатели темы.

Установка и запуск

Требуется Python 3.10 или новее, pip, Tkinter и зависимости из req.txt.

Linux/macOS

python -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r req.txt
python main.py

Windows PowerShell

python -m venv venv
venv\\Scripts\\Activate.ps1
pip install -r req.txt
python main.py

В Debian/Ubuntu при отсутствии Tkinter установите системный пакет:

sudo apt install python3-tk

Зависимости проекта:

customtkinter==6.0.0
darkdetect==0.8.0
packaging==26.3
pillow==12.3.0

Архитектура

main.py создаёт App, вызывает init_page() и запускает mainloop(). Класс App из conf/app.py хранит маршруты, уничтожает текущую страницу и создаёт новую через switch().

app = App()
app.init_page()
app.mainloop()

Каждый экран наследуется от ctk.CTkFrame и получает master и ссылку на приложение. Переход выполняется так:

self.app.switch("login")
self.app.switch("login", prefill_login=username)

Маршруты экранов

Маршруты объявлены в src/forms/page_register.py. Стартовый маршрут сейчас равен testview.

ИмяКлассНазначение
testviewtestviewЭкспериментальный стартовый экран
loginAuthorisationФорма входа
signupRegistrationФорма регистрации

Чтобы открывать вход сразу после запуска, измените init_page = "testview" на init_page = "login".

Новый экран можно добавить в список routes или зарегистрировать вызовом:

app.register("dashboard", Dashboard)

Формы входа и регистрации

Вход

Класс Authorisation проверяет заполненность логина и пароля, затем минимальную длину пароля. При корректных демонстрационных данных он вызывает маршрут dashboard. Пока этот маршрут не зарегистрирован, успешный вход завершится ошибкой KeyError.

Регистрация

Класс Registration проверяет имя пользователя длиной от 3 символов, простой формат email, пароль длиной от 6 символов и совпадение подтверждения. После проверки данные печатаются в консоль, но не сохраняются.

Логин: admin
Пароль: admin123

Файл src/ui/theme.py задаёт тёмный режим, синюю тему, цвета ошибок и фабрики make_entry(), make_button(), make_error_label().

Ограничения текущей версии

  1. Нет базы данных и постоянного хранения пользователей.
  2. Нет реальной авторизации и безопасного хеширования паролей.
  3. Маршрут dashboard вызывается, но отсутствует в реестре.
  4. prefill_login передаётся в экран входа, но пока не используется.
  5. api.py и conf.json пусты.
  6. Автоматические тесты отсутствуют.
  7. Демонстрационный пароль находится в исходном коде и не подходит для реального приложения.

Рекомендуемое развитие

  1. Добавить слой доступа к SQLite или внешнему API.
  2. Хранить только хеши паролей с помощью проверенной библиотеки.
  3. Зарегистрировать полноценный экран dashboard.
  4. Реализовать автозаполнение логина из prefill_login.
  5. Вынести пользовательские настройки в конфигурацию без секретов.
  6. Добавить тесты валидации, маршрутизации и сценариев входа.

Проверка и отладка

Проверка синтаксиса:

python -m compileall main.py conf src

Ошибка ModuleNotFoundError: customtkinter означает, что не установлены зависимости или не активировано виртуальное окружение. Ошибка KeyError: 'dashboard' означает, что нужно добавить маршрут dashboard либо изменить переход в обработчике входа.

Служебные каталоги venv/ и файл db.sqlite3 уже указаны в .gitignore. Не добавляйте в репозиторий токены, пароли и другие секреты.
